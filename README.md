# Alerta para Todos · Mobile

Versión móvil de **Alerta para Todos**, un sistema de alertas de emergencia accesible para personas con discapacidad auditiva, visual y adultos mayores. Está hecha con HTML, CSS y JavaScript a partir de los mockups de Figma (MM-01 a MM-08), para pantallas de 390 px.

## Qué funciona

- Todos los botones y la barra inferior llevan a su pantalla, igual que el prototipo de Figma.
- Los interruptores de canales y el alto contraste se activan y desactivan; se guardan al pulsar "Guardar".
- Si guardas "Alto contraste" activado, la alerta se abre en modo alto contraste (MM-08).
- En la alerta se puede escuchar, repetir, agrandar el texto y pasar al siguiente paso.
- En Solicitar ayuda se elige el tipo de asistencia.
- En el Historial se puede buscar y filtrar con los chips.

## Cómo verlo

Abre `index.html` en el navegador del celular, o en la computadora con las herramientas de desarrollador en modo celular. También se puede publicar gratis con GitHub Pages.

Guía de estilos: tipografía Inter, azul #1565C0, celeste #E3F2FD, rojo de emergencia #D32F2F, verde #2E7D32.
